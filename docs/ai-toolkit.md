# AI Toolkit

This document outlines the free AI tools utilized throughout the AI-assisted development track to support architectural planning, research, coding assistance, and iterative code review.

## Readiness Checklist

- [ ] Claude account ready
- [ ] ChatGPT account ready
- [ ] Gemini account ready
- [ ] Perplexity account ready

## AI Tools & Intended Purpose

### 1. Claude
* **Role:** Primary development tutor, design mentor, and pressure-testing assistant.
* **Intended Purpose:** In-depth architectural critiques, persona-driven code reviews, project custom instructions, and sitemap/decision validation.

### 2. ChatGPT
* **Role:** General ideation, logic breakdown, and alternative perspective generator.
* **Intended Purpose:** Brainstorming problem scenarios, comparing API design patterns, and cross-referencing implementation approaches.

### 3. Gemini
* **Role:** High-context analysis and multi-source code synthesis.
* **Intended Purpose:** Rapid code explanation, debugging workflows, and processing extensive reference material.

### 4. Perplexity
* **Role:** Real-time technical search and verified documentation engine.
* **Intended Purpose:** Querying up-to-date Python package ecosystems, library version compatibility, and finding official API documentation sources.
