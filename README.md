* `README.md` — Project context, status tracking, and setup overview

## Week 1 — Portfolio Direction

This phase defines the strategic direction, sitemap, and AI tooling foundation for a Python Developer portfolio build:

* **Focused Portfolio Sitemap:** Linear sitemap designed around the Python developer proof statement, target audience (recruiters and hiring managers), and primary contact action.
* **AI Toolkit:** Setup checklist and role definitions across Claude, ChatGPT, Gemini, and Perplexity.
* **Claude Project Configuration:** Custom instructions and tutor persona configured for the 8-week build.
* **Sitemap Pressure-Test:** Critical prompt crafted to validate sections against the visitor journey.
* **Decision Framework:** Documenting iterative improvements adopted from AI pressure-testing.
